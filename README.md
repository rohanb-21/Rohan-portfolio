# Rohan Bharat — Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript. No build step or package installation is required.

## Files

- `index.html` — page structure and project content
- `style.css` — responsive dark theme, 3D interactions, layout, and motion
- `script.js` — project filters/details, interactive 3D elements, mobile navigation, scroll effects, and profile links
- `rohan-bharat.png` — portrait image used in the hero

Keep all four files in the same folder when previewing or deploying.

## Preview locally

Open `index.html` in a browser. Or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Vercel

1. Push the contents of this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Select **Other** as the framework preset if prompted. Leave the build command empty and use `./` as the output directory.
4. Deploy. Any new commit pushed to the connected repository will trigger a redeploy.
